# แผนปรับปรุงระบบรอบถัดไป

จากงานที่ทำมาทั้งหมด ยังมีจุดที่ค้างหรือควรปรับปรุง เรียงตามความสำคัญ:

## 1. ความปลอดภัย: รหัสผ่านพนักงาน (สำคัญสูงสุด)
ปัจจุบันระบบล็อกอินเทียบรหัสผ่านแบบข้อความธรรมดา (plain text) กับ `password_hash` — ใครเข้าถึงฐานข้อมูลได้จะเห็นรหัสผ่านทุกคน
- เปลี่ยน edge function `staff-auth` ให้ hash รหัสผ่านจริง (bcrypt/sha-256 + salt) ตอนสร้าง/เปลี่ยนรหัส
- เขียน migration แปลงรหัสผ่านเดิมทั้งหมดเป็น hash (ผู้ใช้ล็อกอินด้วยรหัสเดิมได้เหมือนเดิม)
- ทดสอบล็อกอิน admin/kopi หลังแปลง

## 2. ออเดอร์ออฟไลน์: side effects ไม่ idempotent
ตอนนี้เมื่อออเดอร์ออฟไลน์ซิงก์ขึ้น server แล้ว side effects (แจ้งเตือน LINE/Discord, ตัดสต็อก, แต้มสมาชิก, เลขคิว) อาจทำซ้ำหรือทำไม่ครบ
- เพิ่ม flag `side_effects_done` บน orders — side effects รันเฉพาะเมื่อยังไม่เคยทำ
- ตัดสต็อก/แต้มสมาชิกผูกกับ order_id ป้องกันการหัก/ให้ซ้ำ

## 3. เครื่องพิมพ์ Star USB บนแอป Android
โค้ดและสคริปต์ติดตั้งพร้อมแล้ว แต่ยังไม่ได้ทดสอบกับเครื่องพิมพ์จริง
- รอผลทดสอบจากคุณ (รัน setup-star-printer.ps1 → build APK → เสียบเครื่องพิมพ์ → กดทดสอบพิมพ์)
- ถ้าพิมพ์ได้ จะปิดงานนี้; ถ้าไม่ได้ จะ debug ตามอาการ

## 4. ปุ่มเมนู 3 ขีดบนหน้า WiFi Vouchers
หน้านี้ไม่มี top bar จึงไม่มีปุ่มเมนูบนมือถือ — เพิ่มปุ่ม 3 ขีดให้เหมือนหน้าอื่น

## 5. ชื่อแอปสำหรับลง Play Store / App Store
ยังไม่ได้ตัดสินใจ — ตัวเลือก: Brewly POS, KopiDesk, Aile POS, CupCount, Baristo, ขายดี POS
- เมื่อเลือกชื่อแล้ว จะตั้ง applicationId + app_name + ไอคอนให้พร้อมลงสโตร์

## 6. ปรับปรุงเล็กๆ น้อยๆ (ทำรวมในรอบเดียว)
- PWA install prompt: ทดสอบบน iPad จริง (ตรวจ MacIntel + touch แล้ว แต่ยังไม่ยืนยันบนเครื่องจริง)
- ตรวจข้อความแจ้งเตือน LINE รูปแบบใหม่บนออเดอร์จริง 1 รอบ

## ขั้นตอนดำเนินการ
1. ทำข้อ 1 (รหัสผ่าน) และข้อ 2 (ออฟไลน์) ก่อน เพราะกระทบความปลอดภัยและข้อมูล
2. ทำข้อ 4 และ 6 รวมกัน
3. ข้อ 3 รอผลทดสอบจากคุณ, ข้อ 5 รอคุณเลือกชื่อ

## รายละเอียดทางเทคนิค
- `staff-auth` edge function: เพิ่ม hashing ด้วย Web Crypto (sha-256 + salt per user), เก็บรูปแบบ `salt:hash`
- Migration: แปลง plain-text เดิมเป็น `salt:hash` โดยใช้ค่าเดิมเป็น input
- orders: เพิ่มคอลัมน์ `side_effects_done boolean default false` + GRANT ตามมาตรฐาน
- Stock deduction: เช็ก log ตาม order_id ก่อนหักซ้ำ

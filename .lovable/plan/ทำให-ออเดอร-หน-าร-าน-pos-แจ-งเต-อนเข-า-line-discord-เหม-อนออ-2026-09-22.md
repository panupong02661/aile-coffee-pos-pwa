# ทำให้ออเดอร์หน้าร้าน (POS) แจ้งเตือนเข้า LINE/Discord เหมือนออเดอร์ออนไลน์

## สาเหตุที่ตรวจพบ

- หน้าจอชำระเงินของ POS **ไม่ได้เรียกระบบแจ้งเตือนเลย** ในโค้ดมีคอมเมนต์กำกับไว้ว่าเคยถูกถอดออก (`PaymentModal.tsx` บรรทัด 492)
- ออเดอร์จากแอปลูกค้าแจ้งเตือนได้ เพราะหน้าสั่งซื้อออนไลน์เรียกฟังก์ชันแจ้งเตือนโดยตรงหลังบันทึกออเดอร์
- ตัวดักจับออเดอร์แบบเรียลไทม์ (ตัวที่ควรจะครอบคลุม POS) ใช้งานไม่ได้จริง เพราะกติกาความปลอดภัยของตาราง orders อนุญาตให้เห็นเฉพาะออเดอร์ของสาขาที่ส่งรหัสสาขามากับคำขอ ซึ่งช่องทางเรียลไทม์ไม่ได้ส่งค่านี้ไปด้วย จึงไม่มีสัญญาณออเดอร์ POS เข้ามา
- ฝั่งเซิร์ฟเวอร์รองรับ `pos_orders` อยู่แล้ว (เห็นได้จาก log ของฟังก์ชันแจ้งเตือน)

## สิ่งที่จะทำ

1. เมื่อชำระเงินสำเร็จที่หน้าขาย ให้ส่งข้อมูลออเดอร์เข้าระบบแจ้งเตือนเดียวกับออเดอร์ออนไลน์
   - ทำงานเบื้องหลัง ไม่ถ่วงเวลาปิดการขาย ถ้าส่งไม่สำเร็จจะไม่กระทบการขาย
   - ส่งเฉพาะครั้งเดียวต่อออเดอร์ ไม่ส่งซ้ำตอนพิมพ์ใบเสร็จซ้ำ
   - เคารพสวิตช์ "ออเดอร์ POS" ในหน้าตั้งค่าแจ้งเตือน ถ้าปิดอยู่ก็ไม่ส่ง
2. ครอบคลุมเส้นทางขายอื่นที่บันทึกออเดอร์เองด้วย: แยกบิล และโหมดออฟไลน์ที่ซิงก์ขึ้นภายหลัง
3. ปิดการทำงานซ้ำซ้อนของตัวดักจับเรียลไทม์ ไม่ให้มีโอกาสส่งซ้ำสองทาง
4. ทดสอบจริง: ยิงฟังก์ชันแจ้งเตือนด้วยข้อมูลออเดอร์ POS แล้วตรวจ log ว่าเข้าทั้ง LINE และ Discord

## รายละเอียดทางเทคนิค

- ใน `src/components/PaymentModal.tsx` หลังบันทึก `orders` + `order_items` สำเร็จ เรียก `supabase.functions.invoke('send-order-notification')` แบบ fire-and-forget
- payload ใช้รูปแบบเดียวกับ `GlobalNotificationProvider.tsx`: `order_number`, `total_amount`, `items_count`, `payment_method`, `order_source: 'pos'`, `status`, `created_at`, ข้อมูลลูกค้า, `order_items` พร้อม addon และต้องมี **`shop_id`** (จำเป็นสำหรับการเลือกบัญชี LINE ต่อสาขา)
- กันส่งซ้ำด้วย `Set` ของ order id ในหน่วยความจำฝั่งหน้าเว็บ ร่วมกับ outbox ฝั่งเซิร์ฟเวอร์ที่มีอยู่แล้ว
- เพิ่ม helper ร่วม (เช่น `src/utils/orderNotify.ts`) แล้วเรียกจาก `PaymentModal.tsx`, `SplitBillModal.tsx` และ `useOfflinePOS.ts`
- ใน `GlobalNotificationProvider.tsx` ให้ข้ามการเรียกฟังก์ชันสำหรับออเดอร์ที่มาจาก POS (คงพฤติกรรม UI เดิมไว้)
- ตรวจผลด้วยเครื่องมือยิง edge function + อ่าน log ของ `send-order-notification`

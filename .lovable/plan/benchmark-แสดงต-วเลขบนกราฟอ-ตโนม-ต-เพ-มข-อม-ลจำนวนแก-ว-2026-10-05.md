# Benchmark: แสดงตัวเลขบนกราฟอัตโนมัติ + เพิ่มข้อมูลจำนวนแก้ว

## สิ่งที่จะทำ

1. **แสดงตัวเลขบนกราฟทุกอันโดยไม่ต้องแตะ** — ตอนนี้ต้องเอาเมาส์/นิ้วไปแตะแท่งกราฟถึงเห็นตัวเลข จะเปลี่ยนเป็นแสดงตัวเลขไว้บนหัวแท่งกราฟ (และบนชิ้นกราฟวงกลม) ตลอดเวลา ได้แก่:
   - กราฟเปรียบเทียบรายได้ → แสดง ฿1,223 บนหัวแท่ง
   - กราฟเปรียบเทียบออเดอร์ → แสดงจำนวนออเดอร์บนหัวแท่ง
   - กราฟยอดเฉลี่ยต่อออเดอร์ → แสดงยอดเฉลี่ยบนหัวแท่ง
   - กราฟวงกลมสัดส่วนรายได้ → แสดงชื่อร้าน + เปอร์เซ็นต์ + ยอดเงิน

2. **เพิ่มข้อมูล "จำนวนแก้ว"** (นับจำนวนชิ้นสินค้าทุกชิ้นในออเดอร์ เช่น ออเดอร์ที่สั่ง 3 แก้ว นับเป็น 3) :
   - การ์ดสรุปด้านบนเพิ่มช่อง "แก้วรวม" (รวมทุกร้าน หรือเฉพาะสาขาที่เลือก)
   - กราฟใหม่ "เปรียบเทียบจำนวนแก้ว" ในแท็บเปรียบเทียบ
   - การ์ด "รายละเอียดแต่ละร้าน" เพิ่มบรรทัดจำนวนแก้ว
   - แท็บจัดอันดับเพิ่มอันดับ "จำนวนแก้วขายได้"

## Technical

- **Migration**: แก้ฟังก์ชัน `get_shop_benchmark` (DROP + CREATE) เพิ่มคอลัมน์ `total_items` = ผลรวม `order_items.quantity` ของออเดอร์ในร้านนั้นตั้งแต่ `p_start` (ยังคง admin only, SECURITY DEFINER เหมือนเดิม)
- `src/pages/ShopBenchmark.tsx`:
  - เพิ่ม `totalItems` ใน `ShopStats` อ่านจาก `row.total_items`
  - ใช้ `<LabelList dataKey="..." position="top" formatter={...} />` ของ recharts บน Bar ทุกกราฟ (ตัวเลขเล็ก fontSize 11)
  - Pie chart: label แสดง `ชื่อ ฿ยอด (%)`
  - การ์ดสรุปเปลี่ยนเป็น 5 ช่อง (grid-cols-2 md:grid-cols-5) เพิ่ม "แก้วรวม" พร้อมไอคอน Coffee
  - เพิ่มกราฟ Bar "เปรียบเทียบจำนวนแก้ว" และอันดับแก้วในแท็บจัดอันดับ
- ทดสอบ: เปิดหน้า Benchmark เห็นตัวเลขบนกราฟทันทีโดยไม่แตะ และเห็นจำนวนแก้วตรงกับยอดขายจริง

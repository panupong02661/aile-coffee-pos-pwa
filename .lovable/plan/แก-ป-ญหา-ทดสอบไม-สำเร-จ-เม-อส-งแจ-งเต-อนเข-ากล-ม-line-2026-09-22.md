# แก้ปัญหา "ทดสอบไม่สำเร็จ" เมื่อส่งแจ้งเตือนเข้ากลุ่ม LINE

## สิ่งที่ตรวจพบจริง

จาก log ฝั่งเซิร์ฟเวอร์ ตอนกดปุ่มทดสอบ ระบบส่งข้อความไปยังปลายทาง `Cb100df9628c9ca06a95cf5e7c48b2996` และ LINE ตอบกลับว่า `Failed to send messages` ทุกครั้ง แปลว่าคำสั่งส่งถึง LINE แล้ว แต่ LINE ปฏิเสธปลายทางนี้

สาเหตุที่เป็นไปได้ (ยังไม่ยืนยันว่าอันไหน เพราะระบบไม่ได้บันทึกรหัสข้อผิดพลาดจริงจาก LINE):
- บัญชีทางการ (bot) ยังไม่ได้อยู่ในกลุ่มนั้น หรือถูกเตะออกแล้ว
- รหัสกลุ่มคัดลอกมาไม่ตรง (ปกติรหัสกลุ่มขึ้นต้นด้วย C แล้วตามด้วยตัวเลข/ตัวอักษรพิมพ์เล็ก)
- กลุ่มนี้มาจาก LINE Official Account คนละบัญชีกับ token ที่ระบบใช้อยู่

ตอนนี้ข้อความที่ผู้ใช้เห็นคือ "Edge Function returned a non-2xx status code" ซึ่งไม่ได้บอกสาเหตุอะไรเลย

## สิ่งที่จะทำ

1. **บอกสาเหตุจริงแทนข้อความกำกวม**
   ให้ระบบส่งข้อความกลับมาพร้อมรหัสและคำอธิบายจริงจาก LINE แล้วหน้าตั้งค่าแสดงเป็นภาษาไทย เช่น
   - "บัญชีทางการยังไม่ได้อยู่ในกลุ่มนี้ กรุณาเชิญเข้ากลุ่มก่อน"
   - "รหัสกลุ่มไม่ถูกต้อง"
   - "Token ไม่ถูกต้องหรือหมดอายุ"

2. **ตรวจก่อนส่ง**
   ก่อนส่งข้อความทดสอบเข้ากลุ่ม ให้ระบบถาม LINE ก่อนว่ากลุ่มนี้มีบัญชีทางการอยู่จริงไหม ถ้าไม่ ให้แจ้งทันทีพร้อมวิธีแก้ โดยไม่ต้องรอข้อความส่งล้มเหลว

3. **ช่วยหารหัสกลุ่มให้ถูก**
   เพิ่มปุ่ม/คำแนะนำในหน้าตั้งค่า: เชิญบัญชีทางการเข้ากลุ่ม แล้วพิมพ์ข้อความอะไรก็ได้ในกลุ่ม ระบบจะตอบรหัสกลุ่มกลับมาให้คัดลอกมาวางได้ตรง ๆ (ความสามารถนี้มีอยู่แล้วฝั่งเซิร์ฟเวอร์ แค่ยังไม่มีคำแนะนำที่ชัดในหน้าจอ)

4. **เก็บ log ให้ตรวจสอบได้**
   บันทึกรหัสสถานะและรายละเอียดจาก LINE ทุกครั้งที่ส่งไม่ผ่าน เพื่อไล่ปัญหาครั้งต่อไปได้เร็ว

## รายละเอียดทางเทคนิค

- `supabase/functions/line-messaging/index.ts`: ใน action `send` ให้ log `response.status` + body, ส่งกลับเป็น JSON `{ success:false, status, lineError }` ด้วย HTTP 200 (แทน throw 500) เพื่อให้ client อ่านสาเหตุได้; เพิ่ม action `verifyTarget` เรียก `GET /v2/bot/group/{groupId}/summary` (หรือ `/room/{roomId}/members/count`) เมื่อ ID ขึ้นต้นด้วย C/R
- `src/pages/NotificationPage.tsx`: ปุ่มทดสอบเรียก `verifyTarget` ก่อน แล้วค่อย `send`; แปลง status 400/403/404 เป็นข้อความไทยที่บอกวิธีแก้ และแสดงรายละเอียดดิบไว้ในบรรทัดรอง

## หมายเหตุ

การแก้นี้ทำให้ทราบสาเหตุชัดเจน แต่ถ้าสาเหตุคือบัญชีทางการไม่ได้อยู่ในกลุ่ม จะต้องเชิญบอทเข้ากลุ่มด้วยตนเองในแอป LINE ระบบทำแทนไม่ได้

# แก้ Benchmark ร้านค้าไม่โหลด + เลือกสาขาแล้วยังขึ้นทุกสาขา

## สาเหตุ (จากข้อความแจ้งเตือนในรูป)
1. **ไม่โหลด:** ระบบแนบรหัสร้านที่กำลังใช้อยู่เข้าไปในทุกคำขอข้อมูลโดยอัตโนมัติ รวมถึงคำขอสรุป Benchmark ด้วย ฟังก์ชันสรุปไม่รู้จักค่านี้เลยแจ้งว่า "Could not find the function ... (p_start, shop_id)" ปัญหานี้เกิดตอนเลือกร้านไว้ในเครื่องแล้ว ส่วนตอนผมทดสอบไม่ได้เลือกร้านไว้ จึงเปิดได้
2. **เลือกสาขาไม่มีผล:** ตัวเลือกสาขามีผลแค่แท็บ "รายละเอียดแต่ละร้าน" ส่วนการ์ดสรุป กราฟ และอันดับยังใช้ข้อมูลทุกร้าน

## สิ่งที่จะทำ
1. ไม่แนบรหัสร้านอัตโนมัติในคำขอที่เรียกฟังก์ชันสรุป (Benchmark และฟังก์ชันอื่นแบบเดียวกัน) ทำให้หน้าโหลดได้ทุกกรณี
2. ตอนเลือกสาขา ให้การ์ดสรุป (จำนวนร้าน / รายได้ / ออเดอร์ / สมาชิก) กราฟ และอันดับ แสดงเฉพาะสาขาที่เลือก ส่วน "ทุกร้าน" แสดงเหมือนเดิม
3. ทดสอบ: ล็อกอิน admin โดยเลือกร้านไว้ก่อน → เปิด Benchmark ต้องโหลดได้ → เลือกสาขาเดียว ตัวเลขและกราฟต้องเหลือเฉพาะสาขานั้น

## Technical
- `src/integrations/supabase/client.ts` scopedFetch: ข้ามการ inject shop_id (query param และ body) เมื่อ path ขึ้นต้นด้วย `rpc/` โดยยังส่ง header `x-shop-id` เหมือนเดิม
- `src/pages/ShopBenchmark.tsx`: totals, comparisonData, revenueShareData และรายการอันดับใช้ `filteredStats` แทน `shopStats`

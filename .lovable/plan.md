2. จึงลบแอปเก่า (กดค้างไอคอนแอป → ถอนการติดตั้ง) — ถ้าลบตอนยังมีออเดอร์ค้าง ออเดอร์จะหายถาวร

## ขั้นตอนทำแอปใหม่

### ขั้นที่ 1: เปิด PowerShell
กด Start → พิมพ์ `PowerShell` → Enter

### ขั้นที่ 2: พิมพ์คำสั่งทีละบรรทัด (Enter ท้ายแต่ละบรรทัด)
```
cd C:\Users\panup\aile-coffee-pos-pwa
git pull
npm install
npm run build
npx cap sync android
npx cap open android
```
- `git pull` ดึงโค้ดเวอร์ชันใหม่ล่าสุด ถ้าขึ้น error (เช่น not a git repository) ให้แจ้งมา จะเปลี่ยนเป็นวิธีดาวน์โหลดโค้ดจาก Lovable แทน
- คำสั่งสุดท้ายเปิดโปรแกรม **Android Studio** (ถ้ายังไม่ได้ติดตั้ง ดาวน์โหลดที่ developer.android.com/studio ก่อน)

### ขั้นที่ 3: ตั้งเลขเวอร์ชันใน Android Studio
1. เปิดไฟล์ `android/app/build.gradle` (แถบซ้าย: app → build.gradle)
2. แก้ `versionCode` เป็นเลขที่**มากกว่ารอบก่อน** (เช่น 1 → 2)
3. แก้ `versionName` เป็น `"1.2.0"`
4. กด **Sync Now** ที่แจ้งเตือนมุมบน

### ขั้นที่ 4: สร้างไฟล์แอป (APK)
1. เมนู **Build → Generate Signed Bundle / APK** → เลือก **APK** → Next
2. ถ้า**มี keystore เดิม**: กด **Choose existing** แล้วเลือกไฟล์ที่หาเจอ กรอกรหัสผ่านเดิม
3. ถ้า**keystore หาย**: กด **Create new...** สร้างใหม่ที่ `C:\keystore\aile-coffee.jks` (เก็บแยกนอกโฟลเดอร์โปรเจกต์) ตั้งรหัสผ่านและ**จดเก็บไว้ให้แน่น**
4. Next → เลือก **release** → Finish → รอสร้างเสร็จ
5. ไฟล์ APK จะอยู่ที่ `android\app\release\app-release.apk`

### ขั้นที่ 5: ติดตั้งบนแท็บเล็ต/มือถือ
1. ส่ง `app-release.apk` เข้าเครื่อง (LINE ส่งหาตัวเอง / คลาวด์ / USB)
2. เปิดไฟล์เพื่อติดตั้ง (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" ถ้ามีถาม)
3. ถ้าใช้ keystore เดิม → ติดตั้งทับได้เลย ไม่ต้องลบแอปเก่า
4. ถ้าสร้าง keystore ใหม่ → ต้องลบแอปเก่าออกก่อน

### ขั้นที่ 6: ตรวจว่าสำเร็จ
- เปิดแอป ดูมุมล่างหน้าล็อกอิน ต้องเห็นเลข **1.2.0**

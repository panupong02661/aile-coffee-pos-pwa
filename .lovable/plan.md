## เป้าหมาย

ย้ายดีไซน์ `/pos-v2` มาเป็นหน้า POS จริง (`/` และ `/pos`) โดย **ไม่เปลี่ยนโฟลว์การขายเดิม** — ยังใช้ `useCart`, `useTableOrders`, `AddonModal`, `PaymentModal`, สมาชิก, โปรโมชั่น, พักบิล, บันทึกย้อนหลัง เหมือนเดิมทุกอย่าง เปลี่ยนแค่ "เปลือกหน้าตา"

## แนวทาง

ทำเป็น **skin ใหม่** ของ POS: เก็บ logic ทั้งหมดใน `src/pages/POS.tsx` ไว้เหมือนเดิม แล้วเปลี่ยนเฉพาะส่วน JSX ที่ render กริดเมนู + ตะกร้า ให้ใช้คอมโพเนนต์สไตล์ v2

### 1. ตะกร้าจริงสไตล์ v2 — `src/components/pos/PosCartV2.tsx`
คอมโพเนนต์ใหม่ที่รับ props ชุดเดียวกับ `Cart.tsx` (cartItems, onUpdateQuantity, onRemoveItem, onUpdateDiscount, billDiscount, ...) แต่วาดด้วยสไตล์ v2:
- หัวตะกร้า: ชื่อ + จำนวนชิ้น + เลือกโต๊ะ + ปุ่มวันที่บันทึกย้อนหลัง (คงของเดิม)
- กลาง: รายการสินค้าเลื่อนได้ แต่ละแถวมีปุ่ม +/- , ลบ, และ **ปุ่มส่วนลดรายรายการ** → เปิด `ItemDiscountModal` เดิม แสดง badge ส่วนลดใต้ชื่อสินค้า
- ท้าย (ฟิกไม่เลื่อน): ยอดรวมย่อย / ส่วนลดรายการ / **ส่วนลดทั้งบิล** (แตะเพื่อเปิด `DiscountModal` เดิม รองรับ % และ ฿) / ยอดสุทธิ
- แถวปุ่มลัด: ส่วนลดบิล, พักบิล (`HoldBillModal`), โค้ด/ของขวัญ (`CodeModal`), เคลียร์ตะกร้า
- ปุ่ม "ชำระเงิน" → เปิด `PaymentModal` ตัวเดิม พร้อมค่าที่คำนวณเหมือนเดิม (โปรโมชั่น, สมาชิก, backdate)

เพื่อลดความเสี่ยง จะ **ย้ายตรรกะคำนวณ/handlers จาก `Cart.tsx` มาใช้ซ้ำแบบตรง ๆ** (คัดลอกส่วนคำนวณและการเรียก modal ชุดเดิม ไม่แก้สูตร) — `Cart.tsx` เดิมยังอยู่ ไม่ถูกลบ

### 2. กริดเมนูสไตล์ v2 — `src/components/pos/PosMenuCardV2.tsx`
อิงจาก `PosV2MenuCard` แต่ผูกกับข้อมูลจริง: รูป/โลโก้ร้าน placeholder, badge จำนวนในตะกร้า, กด → `handleMenuItemClick` เดิม (เปิด AddonModal ถ้ามี addon) และเคารพ `gridColumns` / `itemSize` จากการตั้งค่าเดิม

### 3. แถบหมวดหมู่
ใช้แถบ pill สไตล์ v2 (`PosV2CategoryBar`) แทนแถบหมวดใน `Header` เดิม ส่วน `Header` ยังคงไว้สำหรับ ค้นหา / สมาชิก / ตั้งค่าการแสดงผล / sidebar

### 4. โทนสี
ใช้โทน v2 เป็นค่าเริ่มต้นของ POS โดย map ตัวแปร `--posv2-*` เข้ากับ token ของธีมที่มีอยู่ เพื่อให้ dark mode และ theme preset (neon/cyber/glass) กับการตั้งค่าสีของผู้ใช้ยังทำงานได้

### 5. Rollback ปลอดภัย
- คงหน้าเดิมไว้ที่ route `/pos-classic` เผื่อเทียบ/ย้อนกลับ
- `/pos-v2` เดิมยังอยู่จนกว่าจะยืนยันว่าใช้งานจริงได้ครบ

## สิ่งที่ไม่แตะ
`useCart`, `PaymentModal`, `AddonModal`, `ItemDiscountModal`, `DiscountModal`, การพิมพ์ใบเสร็จ, การตัดสต็อก, แต้มสมาชิก, ตารางโต๊ะ, RLS/ฐานข้อมูล

## จุดตรวจหลังทำเสร็จ
เพิ่มสินค้า → addon → ส่วนลดรายรายการ → ส่วนลดทั้งบิล (% และ ฿) → เลือกโต๊ะ/บันทึกโต๊ะ → พักบิล → ชำระเงิน (เงินสด/พร้อมเพย์) → ออเดอร์บันทึกลง DB และตะกร้าเคลียร์

## เป้าหมาย
ทำหน้า POS ดีไซน์ใหม่เป็น **route แยก** ให้ดูก่อน — ไม่แตะหน้า POS จริง (`/`) เลย

## Route ใหม่
`/pos-v2` — เปิดดูได้ทันที ใช้ข้อมูลเมนู/หมวดหมู่จริงจาก `useSupabaseData` (อ่านอย่างเดียว) แต่ตะกร้าเป็น state ในหน้านี้เอง ไม่ยิงบันทึกออเดอร์

## ทิศทางดีไซน์ (เลือกให้เพราะไม่ได้ระบุ)
โทน "กาแฟโมเดิร์น" — พื้นครีมอุ่น, การ์ดขาวมุมโค้งใหญ่, เงานุ่มแทนเส้นขอบเทา, สีเน้น caramel/espresso, ตัวเลขราคาหนาอ่านง่ายบนแท็บเล็ต, แตะแล้วการ์ดยุบเล็กน้อย

## โครงหน้า
```text
+------+---------------------------------+---------------+
| ไอคอน | หัวข้อ + ช่องค้นหา               |  ตะกร้าสินค้า  |
| ซ้าย  | แถบหมวดหมู่ (pill เลื่อนแนวนอน)   |  รายการ+รูปย่อ |
|      | กริดเมนู (รูปเต็ม + ราคาลอย)      |  สรุปยอด      |
|      |                                 |  ปุ่มลัด 4 ปุ่ม |
|      |                                 |  ชำระเงิน     |
+------+---------------------------------+---------------+
```

## ไฟล์ที่จะสร้าง/แก้
- สร้าง `src/pages/preview/PosV2.tsx` — หน้าหลัก ประกอบ layout ทั้งหมด
- สร้าง `src/components/preview/PosV2MenuCard.tsx` — การ์ดเมนูดีไซน์ใหม่
- สร้าง `src/components/preview/PosV2Cart.tsx` — พาเนลตะกร้าดีไซน์ใหม่ (หัว/กลางเลื่อน/ล่างฟิก)
- สร้าง `src/components/preview/PosV2CategoryBar.tsx` — แถบหมวดหมู่ pill
- แก้ `src/App.tsx` — เพิ่ม route `/pos-v2` แบบ lazy
- แก้ `src/index.css` — เพิ่ม token เฉพาะพรีวิว (prefix `--posv2-*`) ไม่ทับ token เดิม

## ไม่แตะ
`src/pages/Index.tsx`, `Cart.tsx`, `MenuGrid.tsx`, `Header.tsx`, PaymentModal, ระบบพิมพ์, ฐานข้อมูล/RLS

## ตรวจงาน
login ผ่าน browser จริง เปิด `/pos-v2` แคปหน้าจอทั้งขนาดเดสก์ท็อปและแท็บเล็ตส่งให้ดู — ชอบแล้วค่อยบอกให้ย้ายไปทับ POS จริง

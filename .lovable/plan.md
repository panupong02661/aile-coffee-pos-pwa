# แก้ความสับสนหน้าตั้งค่าเครื่องพิมพ์

## คำตอบคำถาม: USB Device Path เอามาจากไหน

ช่อง "USB Device Path" (เช่น `/dev/usb/lp0`) เป็นช่องของระบบเว็บ/คอมพิวเตอร์ Linux รุ่นเก่า — **ในแอปแท็บเล็ตไม่ต้องกรอกช่องนี้เลย** เพราะแอปค้นหาเครื่องพิมพ์เองอัตโนมัติผ่านปลั๊กอิน Star

ปุ่ม "ค้นหาเครื่องพิมพ์" มีอยู่แล้ว แต่อยู่**คนละแท็บ**: หน้า ระบบเครื่องพิมพ์ → แท็บ **"Star Printer"** (ไม่ใช่แท็บ "ตั้งค่าเครื่องพิมพ์" ที่มีช่อง USB Device Path) — แท็บ Star Printer จะมีปุ่ม "ค้นหา" มุมขวาบนของการ์ด "เครื่องพิมพ์ที่ใช้ได้" และค้นหาอัตโนมัติตอนเปิดหน้า

ถ้าเปิดแท็บ Star Printer แล้วไม่เห็นปุ่มค้นหา แปลว่าแอปยังไม่ได้ติดตั้งตัวเชื่อมเครื่องพิมพ์ (ต้องรัน setup-star-printer แล้ว build APK ใหม่)

## สิ่งที่จะแก้

1. **แท็บ "ตั้งค่าเครื่องพิมพ์" (PrinterConfiguration.tsx)**
   - เอาตัวเลือก USB และ Bluetooth ออกจาก "ประเภทการเชื่อมต่อ" เหลือแค่ Ethernet / WiFi (แท็บนี้ใช้ได้จริงเฉพาะเครื่องพิมพ์เครือข่าย)
   - ลบช่อง "USB Device Path" ออก เพราะไม่มีที่ใช้จริงและทำให้สับสน
   - เพิ่มข้อความบอกด้านบน: "เครื่องพิมพ์ USB (Star) ให้ตั้งค่าที่แท็บ Star Printer"

2. **แท็บ "Star Printer" (StarPrinterManager.tsx)**
   - เพิ่มข้อความอธิบายสั้น ๆ ใต้ปุ่มค้นหา: "เสียบสาย USB จากเครื่องพิมพ์เข้าแท็บเล็ต (ผ่านอแดปเตอร์ OTG) แล้วกดค้นหา — แอปจะหาเครื่องให้เอง ไม่ต้องกรอกอะไร"
   - ถ้าค้นหาแล้วไม่เจอ แสดงคำแนะนำ: ตรวจอแดปเตอร์ OTG, เปิดเครื่องพิมพ์, อนุญาต USB เมื่อแอนดรอยด์ถาม

## รายละเอียดทางเทคนิค

- `src/components/printer/PrinterConfiguration.tsx`: ลบ SelectItem USB/Bluetooth, ลบ block `usb_path`, เพิ่ม note ชี้ไปแท็บ Star Printer (ไม่แตะ logic บันทึก network printer)
- `src/components/StarPrinterManager.tsx`: เพิ่มข้อความช่วยเหลือในการ์ด "เครื่องพิมพ์ที่ใช้ได้" ทั้งตอนมี/ไม่มีเครื่องที่เจอ
- ไม่แตะปลั๊กอิน native, ไม่แตะ useStarPrinter

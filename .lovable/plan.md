# ทำให้คอมพิวเตอร์ Windows เห็นเครื่องปริ้น Star TSP143III (USB)

ปัญหานี้อยู่ที่ฝั่งคอมพิวเตอร์ ไม่ได้อยู่ที่ระบบ POS — ต้องให้ Windows เห็นเครื่องปริ้นก่อน แล้ว POS ถึงจะพิมพ์ผ่านหน้าต่างพิมพ์ได้

## ขั้นตอนตรวจสอบ (ทำตามลำดับ)

1. **เช็กตัวเครื่อง**: ไฟเขียวต้องติด ฝาปิดสนิท มีกระดาษ ลองกดปุ่ม FEED ค้างตอนเปิดเครื่อง ถ้าพิมพ์หน้าทดสอบออกมาได้ แปลว่าตัวเครื่องปกติ และหน้านั้นจะบอกรุ่น (USB / LAN / Bluetooth)
2. **เช็กสาย**: เสียบเข้าช่อง USB ด้านหลังตัวคอมโดยตรง ไม่ผ่านฮับหรือสายต่อ แล้วลองเปลี่ยนช่อง
3. **เปิด Device Manager** (คลิกขวาที่ปุ่ม Start > Device Manager) แล้วเสียบ/ถอดสาย ดูว่ามีอะไรโผล่หรือหายไปไหม เช่น "Star TSP100", "USB Printing Support" หรือ "Unknown device" มีเครื่องหมายตกใจสีเหลือง
   - ถ้าไม่มีอะไรเปลี่ยนเลย = สาย USB หรือช่องเสีย ให้ลองสายเส้นอื่น
   - ถ้าเป็น Unknown device = ไดรเวอร์ยังไม่ได้ลง
4. **ลงไดรเวอร์ให้ถูกตัว**: โหลด "TSP100 futurePRNT" (หรือ "Star Windows Software Full") จากเว็บ starmicronics.com เลือก Windows แล้วติดตั้ง**ตอนที่เสียบสายและเปิดเครื่องปริ้นอยู่** จากนั้นรีสตาร์ทคอม
5. ถ้ายังไม่ขึ้น: ในหน้า Printers & scanners กด Add device > "The printer that I want isn't listed" > Add a local printer > เลือกพอร์ต USB001 > ยี่ห้อ Star > รุ่น TSP143

## หลังจาก Windows เห็นแล้ว
- ตั้งเป็นเครื่องปริ้นหลัก (ปิดตัวเลือก "Let Windows manage my default printer" ก่อน)
- ในหน้าพิมพ์ของ Chrome ตั้งขนาดกระดาษ 80mm ขอบกระดาษ None แล้วสั่งพิมพ์ใบเสร็จจาก POS

## ส่วนแอป
ไม่ต้องแก้โค้ดในรอบนี้ ถ้าทำครบทุกขั้นแล้วยังไม่ขึ้น ขอรูปหน้า Device Manager ตอนเสียบสาย และรูปป้ายใต้เครื่องปริ้น (บอกรุ่นที่แน่นอน)

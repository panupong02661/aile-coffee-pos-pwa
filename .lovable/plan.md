# ย้ายป้ายข้อมูลลูกค้าขึ้นมาอยู่แถวเดียวกับปุ่มเลือกลูกค้า

## สิ่งที่จะเปลี่ยน
ตอนนี้เมื่อเลือกลูกค้า ป้ายชื่อลูกค้า (เช่น "กิ๊บ | ทอง | X") จะแสดงเป็นแถวใหม่ใต้ปุ่มไอคอนทั้งหมด ทำให้เกิดแถวเพิ่มและกินพื้นที่หน้าจอ

จะย้ายป้ายนี้ขึ้นมาอยู่ในแถวเดียวกัน โดยวางไว้:

```text
[ปุ่มเลือกลูกค้า] [ป้ายลูกค้า: กิ๊บ ทอง X] [Debug] [ค้นหา] [ตั้งค่า] ... [แถบหมวดหมู่]
```

คือ ต่อท้ายปุ่มเลือกลูกค้าทันที และอยู่ก่อนปุ่ม Debug

## รายละเอียดเชิงเทคนิค
- ไฟล์เดียว: `src/components/Header.tsx`
- ย้ายบล็อก `{selectedMember && (...)}` (บรรทัด 173–200) จากใต้แถวปุ่ม ขึ้นไปแทรกหลังปุ่ม `onMemberClick` (บรรทัด 132) ก่อนกลุ่มปุ่ม Debug/ค้นหา/ตั้งค่า
- ปรับให้เข้ากับแถวเดียว: เพิ่ม `flex-shrink-0`, เอา `self-start` ออก, ลดความสูงเป็น `h-9` ให้เท่าปุ่มอื่น
- คอนเทนเนอร์ด้านนอกยังเป็น `flex flex-col gap-1` ได้ตามเดิม (เมื่อไม่มีแถวที่สองจะไม่กินพื้นที่)
- ไม่แตะฟังก์ชันการทำงาน: คลิกป้าย = เปิดรายละเอียดลูกค้า, กด X = ลบลูกค้าออก เหมือนเดิม
- ไม่แก้ไขส่วนอื่นของ POS

# คู่มือการใช้งาน Aile POS พร้อมภาพและ Flow

## ผลงานที่ส่งมอบ
- คู่มือภาษาไทยชื่อ **Aile POS** สำหรับลูกค้าที่สนใจบริการและผู้เริ่มใช้งาน
- ไฟล์ **PDF** พร้อมส่งให้ลูกค้า และ **Word (.docx)** ที่แก้ไขข้อความและภาพได้
- หน้าปก สารบัญ เลขหน้า ภาพประกอบพร้อมหมายเลขกำกับ และแผนผังขั้นตอนการทำงาน
- ใช้ข้อมูลสมมติทั้งหมด ไม่ใส่ข้อมูลลูกค้า ยอดขายจริง รหัสผ่าน หรือข้อมูลเชื่อมต่อบริการ และไม่แต่งราคาแพ็กเกจหรือช่องทางติดต่อ

## 1. ตรวจและจัดสารบัญให้ครบ
ตรวจทุกหน้าที่เปิดใช้งาน ทุกเมนู แท็บ หัวข้อย่อย และหน้าต่างที่เกี่ยวข้องก่อนเขียน โดยทำตารางตรวจความครอบคลุมเพื่อไม่ให้ตกหล่น

รายการเมนูที่ตรวจพบแบ่งเป็น 10 กลุ่ม:
1. **หลัก:** POS, แดชบอร์ด, สรุปกะ/ปิดรอบขาย, Benchmark ร้านค้า
2. **ร้านค้าและออเดอร์:** จอครัว, จอลูกค้า, ออเดอร์ออนไลน์, Delivery, จัดการจัดส่ง, ติดตามเดลิเวอรี่, ระบบคิว, จอแสดงคิว, จัดการโต๊ะ
3. **เมนูและสินค้า:** จัดการเมนู, คลังสินค้า, วิเคราะห์ต้นทุน
4. **ลูกค้าและสมาชิก:** จัดการสมาชิก, แอปลูกค้า, จัดการแอปลูกค้า
5. **โปรโมชั่นและกิจกรรม:** Engagement, หน้าที่เปิดจากเมนูโปรโมชั่น, โปรโมชั่นเมนู, คูปอง
6. **พนักงาน:** จัดการพนักงาน, บันทึกเวลา, สิทธิ์ผู้ใช้
7. **รายงานและวิเคราะห์:** รายงาน, รายงานขั้นสูง, Analytics, วิเคราะห์ลูกค้า
8. **การเงิน:** Financial Dashboard, QR PromptPay, ระบบเครดิต
9. **การสื่อสาร:** แจ้งเตือน, LINE Messaging, จัดการรีวิว, WiFi ลูกค้า
10. **ตั้งค่าและระบบ:** ตั้งค่าร้าน, ตั้งค่าธุรกิจ, เครื่องพิมพ์, ความปลอดภัย, แนะนำความปลอดภัย, สร้างแอปมือถือ, ข้อมูลระบบ POS

รวมหน้าเพิ่มเติมนอกเมนูหลัก เช่น เข้าสู่ระบบ สมัครสมาชิก ติดตามคิว ติดตั้ง PWA และตั้งค่ามือถือ ตลอดจนหัวข้อย่อยของหน้ารวมด้านการเงิน ลูกค้า เทคโนโลยี และความปลอดภัยที่ตรวจพบว่าใช้งานได้จริง

หน้าที่เป็นทางเข้าไปหน้าเดียวกันจะระบุทุกทางเข้าและอ้างอิงบทเดียวกัน ส่วนหน้าตัวอย่างดีไซน์จะแยกไว้ในภาคผนวก ไม่ปะปนกับงานขายจริง

## 2. เขียนวิธีใช้ทุกหัวข้อ
แต่ละหัวข้อประกอบด้วย:
- ใช้ทำอะไร และใครเป็นผู้ใช้งาน
- สิ่งที่ต้องเตรียมหรือตั้งค่าก่อนเริ่ม
- เปิดจากเมนูใด และกดอะไรตามลำดับ
- คำอธิบายช่องกรอก ปุ่ม ตัวเลือก และแท็บที่เกี่ยวข้อง
- ผลลัพธ์ที่ควรเห็น ตัวอย่างสถานการณ์ และข้อควรระวัง
- ภาพหน้าจอหรือภาพจำลองที่ตรงกับหัวข้อนั้น

แยกความสามารถที่ตรวจใช้งานได้ออกจากหน้าสาธิตหรือส่วนที่ยังยืนยันไม่ได้ เพื่อไม่ให้คู่มือสัญญาความสามารถเกินจริง

## 3. ภาพประกอบด้วยข้อมูลตัวอย่าง
- ใช้หน้าจอของระบบปัจจุบันในสภาพแวดล้อมสาธิตที่แยกจากข้อมูลจริง โดยไม่บันทึกคำสั่งซื้อหรือแก้ค่าร้านจริง
- เตรียมร้าน เมนู ออเดอร์ สมาชิก สต็อก และรายงานสมมติให้สอดคล้องกันตลอดเล่ม
- เน้นภาพแท็บเล็ตสำหรับ POS พร้อมภาพคอมพิวเตอร์และแอปลูกค้าบนมือถือในบทที่เกี่ยวข้อง
- ใส่หมายเลขกำกับจุดที่ต้องกด และภาพขยายเมื่อข้อความเล็กเกินไป
- หากหน้าใดเปิดตรวจไม่ได้ ให้ใช้ภาพจำลองจากหน้าจอและส่วนประกอบที่ตรวจแล้ว พร้อมระบุว่า **ภาพจำลองประกอบคู่มือ** ไม่เรียกว่าเป็นภาพที่ทดสอบจริง

## 4. แผนผังการใช้งาน
ทำ Flow พร้อมอ้างอิงบทคู่มือสำหรับ:
- เริ่มใช้งานครั้งแรก: ตั้งค่าร้าน → เมนู/ราคา → ภาษี/ใบเสร็จ → เครื่องพิมพ์ → พนักงาน → พร้อมขาย
- ขายหน้าร้าน: เลือกสินค้า → Add-on → สมาชิก/ส่วนลด → ชำระเงิน → ใบเสร็จ/ใบครัว/สติ๊กเกอร์ → คิว
- จัดการโต๊ะและการชำระแบบแยกบิล/หลายวิธี โดยอธิบายตามการทำงานที่ตรวจพบ
- ออเดอร์ออนไลน์และจัดส่ง: ลูกค้าสั่ง → ร้านรับ → ครัวเตรียม → ส่งมอบ/จัดส่ง → ติดตามสถานะ
- สมาชิกและกิจกรรม: สมัคร → สะสม → รับสิทธิ์ → ใช้สิทธิ์ที่ POS
- คลังสินค้า: วัตถุดิบ → สูตร → ขาย → ตรวจความเคลื่อนไหวและคงเหลือ
- แจ้งเตือน LINE/Discord และรายงานประจำวัน/เดือน
- ปิดกะ → ตรวจรายงาน → ดูรายละเอียดบิล → พิมพ์ย้อนหลัง
- ออฟไลน์ → รับรายการขาย → กลับออนไลน์ → ตรวจรายการซิงก์

## 5. จัดเล่มและตรวจคุณภาพ
- จัดหน้า A4 อ่านง่าย ใช้ฟอนต์ไทย ภาพคมชัด และสารบัญค้นหาหัวข้อได้
- สร้าง PDF และ Word จากเนื้อหาชุดเดียวกันเพื่อให้ตรงกัน
- ตรวจตารางครอบคลุมทุกหน้า/เมนู/แท็บเทียบกับเนื้อหาและภาพ
- ตรวจการแสดงผลทุกหน้า: ภาษาไทย ภาพ เลขหน้า สารบัญ ข้อความล้น และข้อมูลส่วนตัว
- ส่งไฟล์ทั้งสองใน Files พร้อมแจ้งรายการที่ยังไม่สามารถยืนยันการทำงานจริงได้อย่างชัดเจน

## รายละเอียดการจัดทำและข้อจำกัด
- งานนี้เป็นเอกสาร ไม่ปรับหน้าตาหรือการทำงานของ POS และไม่เพิ่มหน้าเว็บคู่มือ
- ตรวจรายการหน้าและเมนูจากระบบ แล้วสำรวจรายละเอียดแต่ละกลุ่มควบคู่กัน
- สถานะการเข้าถึงปัจจุบันเป็นบริการ Supabase ภายนอกที่ไม่สามารถเตรียมเซสชันผู้ใช้ให้อัตโนมัติได้ จึงไม่รับรองว่าจะถ่ายภาพหน้าที่ต้องเข้าสู่ระบบครบได้ทันที; จะเตรียมภาพสาธิตแยกต่างหากและระบุภาพจำลองตามจริง
- ขั้นตอนเครื่องพิมพ์และการติดตั้งแอปจะระบุอุปกรณ์ที่ต้องใช้และข้อจำกัด ไม่อ้างว่าทดสอบเครื่องจริงแล้ว
- จำนวนหน้าขึ้นกับหัวข้อที่ตรวจพบ โดยไม่ย่อจนขั้นตอนหรือเมนูตกหล่น

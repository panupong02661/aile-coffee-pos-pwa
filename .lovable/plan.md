# แก้แท็บ Star Printer ให้มีปุ่มค้นหาเครื่องพิมพ์

## สาเหตุ
หน้า "ระบบเครื่องพิมพ์" → แท็บ "Star Printer" แสดงฟอร์มตั้งค่าเก่า (ชื่อเครื่อง/รุ่น/USB Device Path) แทนที่จะแสดงส่วนค้นหาเครื่องพิมพ์ ส่วนที่มีปุ่ม "ค้นหา" มีอยู่แล้วแต่แสดงเฉพาะในหน้าตั้งค่าบนมือถือ ไม่ได้อยู่ในแท็บนี้

## สิ่งที่จะทำ
1. แท็บ "Star Printer" แสดงส่วนค้นหาเครื่องพิมพ์ไว้ด้านบนสุด: ปุ่ม "ค้นหา", รายชื่อเครื่องที่เจอ, ปุ่มเชื่อมต่อ, ปุ่มทดสอบพิมพ์, ปุ่มเปิดลิ้นชัก
2. ฟอร์มตั้งค่าเดิม (ขนาดกระดาษ, ตัดกระดาษอัตโนมัติ ฯลฯ) ย้ายไปอยู่ด้านล่าง
3. ซ่อนช่อง "USB Device Path" ทั้งหมด และถ้าค่าที่บันทึกไว้เดิมเป็น USB ให้แสดงข้อความ "USB ใช้ปุ่มค้นหาด้านบน" แทนช่องกรอก
4. ถ้าเปิดผ่านเว็บบนคอมพิวเตอร์ จะเห็นข้อความว่าต้องใช้แอปบนแท็บเล็ต; ถ้าเปิดในแอปแต่ยังไม่ได้ติดตั้งตัวเชื่อมเครื่องพิมพ์ จะเห็นข้อความบอกให้รันขั้นตอนติดตั้งและ build ใหม่

## Technical
- `src/pages/PrinterSettings.tsx`: ใน TabsContent "config" render `<StarPrinterManager />` ก่อน `<PrinterConfiguration />`
- `src/components/printer/PrinterConfiguration.tsx`: ไม่ render input usb_path; ถ้า connection_type เป็น usb/bluetooth แสดงข้อความแนะนำแทน

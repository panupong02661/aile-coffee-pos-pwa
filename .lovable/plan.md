# พิมพ์ใบเสร็จอัตโนมัติหลังชำระเงิน + พิมพ์ใบเสร็จย้อนหลังจากหน้ารายงาน

## 1. กด "ชำระเงิน" ที่หน้า POS แล้วพิมพ์ออกเลย
ตอนนี้ปุ่มชำระเงินบันทึกออเดอร์และแสดงตัวอย่างใบเสร็จได้ แต่ยังไม่ได้ส่งงานไปที่เครื่องพิมพ์ จะเพิ่มให้พิมพ์ทันทีหลังชำระสำเร็จ ตามที่ตั้งค่าไว้ในแท็บ "จำนวนการพิมพ์":
- **ใบเสร็จลูกค้า**: พิมพ์ตามจำนวนสำเนาที่ตั้งไว้
- **ใบครัว**: พิมพ์เมื่อเปิด "พิมพ์สำเนาร้านอัตโนมัติ" ไว้ (แสดงชื่อเมนู ตัวเลือกเสริม จำนวน และประเภทออเดอร์)
- **สติ๊กเกอร์**: พิมพ์เมื่อเปิดสติ๊กเกอร์และพิมพ์อัตโนมัติไว้ ได้หนึ่งแผ่นต่อแก้ว
- ในแอปแท็บเล็ตจะส่งตรงไปที่เครื่องพิมพ์ Star USB (เป็นภาพ ภาษาไทยออกครบ แบบเดียวกับปุ่มทดสอบ) ส่วนบนคอมจะเปิดหน้าต่างพิมพ์ของเบราว์เซอร์
- ถ้าพิมพ์ไม่ได้ ออเดอร์จะยังบันทึกตามปกติ แอปจะขึ้นสาเหตุให้ และกดพิมพ์ซ้ำจากหน้าใบเสร็จได้
- ตอนไม่มีอินเทอร์เน็ตก็ยังพิมพ์ได้ เพราะใช้ข้อมูลออเดอร์ที่อยู่ในเครื่อง

## 2. หน้ารายงานขั้นสูง: ปุ่มพิมพ์ใบเสร็จย้อนหลัง
- เพิ่มปุ่ม "พิมพ์ใบเสร็จ" ในแต่ละบิล (ข้างส่วนดูรายละเอียดบิล)
- ใบที่พิมพ์ซ้ำจะมีคำว่า "สำเนา (พิมพ์ซ้ำ)" พร้อมวันเวลาที่พิมพ์ เพื่อไม่ให้สับสนกับใบจริง
- ใช้เครื่องพิมพ์ช่องทางเดียวกับข้อ 1

## สิ่งที่คุณต้องทำหลังแก้
ในเว็บใช้ได้ทันที ส่วนในแอปแท็บเล็ตต้อง Build APK ใหม่และติดตั้งทับ (ใช้คำสั่งชุดเดิม ไม่ต้องรันสคริปต์ Star ใหม่ ถ้าไม่ได้ลบโฟลเดอร์ android)

## รายละเอียดทางเทคนิค
- ไฟล์ใหม่ `src/utils/orderPrinting.ts`: `printOrderDocuments(order, { reprint? })` อ่าน `localStorage.printCopiesConfig` (customerReceiptCopies, autoShopCopy/shopReceiptCopies, stickerEnabled+autoSticker/stickerCopies) แล้วสร้างข้อความใบเสร็จ ใบครัว และสติ๊กเกอร์
  - native: `printTextViaStar(text)` ทีละใบ (Kotlin plugin วาดเป็นภาพแล้วตัดกระดาษ)
  - web: iframe ซ่อนกว้าง 80mm + `window.print()` รวมทุกใบ แบ่งหน้าด้วย `page-break-after`
- `PaymentModal.handlePayment`: หลังบันทึกออเดอร์ (local-first) สำเร็จ เรียก `printOrderDocuments` แบบไม่รอ ใช้ข้อมูลจาก cartItems, order_number, ยอดรวม, ส่วนลด, ช่องทางชำระ และเงินทอน; กันพิมพ์ซ้ำด้วย order_number
- `DetailedOrderReport.tsx`: ปุ่ม Printer ต่อบิล → แปลง `order` + `order_items` เป็นข้อมูลแบบเดียวกัน แล้วเรียกด้วย `{ reprint: true }` (พิมพ์เฉพาะใบเสร็จลูกค้า 1 ใบ)
- ทดสอบหน่วยตรรกะเลือกเอกสาร: จำนวนใบตามค่าตั้ง, ปิดใบครัว/สติ๊กเกอร์แล้วต้องไม่พิมพ์, สติ๊กเกอร์ = จำนวนแก้ว

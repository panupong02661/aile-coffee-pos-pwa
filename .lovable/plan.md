# แก้ปุ่มธนบัตรกดซ้ำ + Benchmark ร้านค้าไม่แสดงข้อมูล

## 1. ปุ่มธนบัตรในหน้าชำระเงิน กดซ้ำได้ (บวกเพิ่ม)
- ตอนนี้กดธนบัตรแล้ว "แทนที่" ยอดเดิม → เปลี่ยนเป็น "บวกเพิ่ม" เช่น กด ฿100 สองครั้ง = รับเงิน ฿200, ซื้อ ฿120 เงินทอน ฿80
- ปุ่ม "จ่ายพอดี" ยังตั้งยอดรับเงินเท่ายอดชำระเหมือนเดิม
- เพิ่มปุ่มเล็ก "ล้าง" ข้างหัวข้อธนบัตร เพื่อเริ่มนับใหม่เมื่อกดผิด
- ใช้ทั้งโหมดเงินสด และช่องเงินสดในโหมดผสม (ถ้ามีปุ่มธนบัตร)

## 2. Benchmark ร้านค้าแสดงทุกร้าน
- สาเหตุ: หน้านี้ดึงรายชื่อร้านจากตารางร้านค้าโดยตรงก่อน ซึ่งระบบสิทธิ์จำกัดให้เห็นเฉพาะร้านที่กำลังใช้อยู่ ได้รายชื่อว่าง → ขึ้น "ยังไม่มีข้อมูลร้านค้า" ทันทีโดยไม่เคยดึงยอดขาย
- แก้: ให้ฟังก์ชันสรุป Benchmark (สำหรับ admin เท่านั้น) ส่งชื่อร้าน/ชื่อสาขามาด้วย และหน้าเว็บใช้ข้อมูลจากฟังก์ชันนี้อย่างเดียว
- ถ้าเกิดข้อผิดพลาด (เช่น ไม่ใช่ admin) จะแสดงข้อความชัดเจนแทนหน้าว่าง
- ตรวจสอบหลังแก้: ล็อกอิน admin เปิดหน้า Benchmark ต้องเห็นทั้ง Aile Coffee และ kopi พร้อมยอดขาย

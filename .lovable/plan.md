# แผนทำแอป Android รอบใหม่ (เครื่อง Windows) — เมื่อหาโฟลเดอร์เดิมและ keystore เดิมไม่เจอ

## สถานการณ์ตอนนี้
- หาโฟลเดอร์โปรเจกต์เดิม (`aile-coffee-pos`) ไม่เจอ → ไม่เป็นปัญหา เพราะรอบนี้ต้องใช้โค้ดเวอร์ชันใหม่ล่าสุดอยู่แล้ว เราจะดาวน์โหลดโค้ดใหม่จาก Lovable
- หาไฟล์ keystore เดิม (ไฟล์ `.jks`) ไม่เจอ → ต้องสร้าง keystore ใหม่ และต้อง**ลบแอปเก่าออกจากเครื่องก่อน** แล้วจึงติดตั้งแอปใหม่

## ข้อควรทำก่อนลบแอปเก่า (สำคัญมาก)
1. เปิดแอป POS เดิมที่ติดตั้งไว้ แล้ว**เปิดอินเทอร์เน็ต** รอจนข้อความ "รอซิงก์" จำนวนออเดอร์เป็น 0
   - ออเดอร์ออฟไลน์ที่ยังไม่ได้ส่งขึ้นระบบ จะหายถาวรถ้าลบแอปตอนนั้น
2. เมื่อรอซิงก์หมดแล้ว จึงลบแอปเก่าออก (กดค้างที่ไอคอนแอป → ถอนการติดตั้ง)

## ขั้นตอนทำแอปใหม่ (ทำบนคอม Windows)

### ขั้นที่ 1: ดาวน์โหลดโค้ดใหม่จาก Lovable
1. เปิดเว็บ Lovable โปรเจกต์นี้ในเบราว์เซอร์
2. กดปุ่มที่มุมบน (เมนู ... หรือ Export) → เลือก **Download code / Export code** เป็น ZIP
3. แตกไฟล์ ZIP ไว้ที่ `C:\aile-coffee-pos` (สร้างโฟลเดอร์ใหม่ที่ไดรฟ์ C ตรง ๆ จะง่ายต่อการจำครั้งหน้า)

### ขั้นที่ 2: เปิดโปรแกรมพิมพ์คำสั่ง
1. กดปุ่ม **Start** → พิมพ์ `PowerShell` → กด Enter

### ขั้นที่ 3: พิมพ์คำสั่งตามลำดับ (ทีละบรรทัด กด Enter ท้ายแต่ละบรรทัด)
```
cd C:\aile-coffee-pos
npm install
npm run build
npx cap sync android
npx cap open android
```
- คำสั่งสุดท้ายจะเปิดโปรแกรม **Android Studio** ขึ้นมา (ถ้ายังไม่ได้ติดตั้ง Android Studio ให้ดาวน์โหลดจาก developer.android.com/studio ติดตั้งก่อน)

### ขั้นที่ 4: ตั้งเลขเวอร์ชันใน Android Studio
1. เปิดไฟล์ `android/app/build.gradle` (ดูในแถบซ้าย: app → build.gradle)
2. หาบรรทัด `versionCode` ให้เป็นเลข **2** (หรือเลขมากกว่าเดิม)
3. หาบรรทัด `versionName` ให้เป็น `"1.2.0"`
4. กด **Sync Now** ที่ขึ้นเตือนมุมบน

### ขั้นที่ 5: สร้างไฟล์แอป (APK) และ keystore ใหม่
1. เมนู **Build → Generate Signed Bundle / APK**
2. เลือก **APK** → Next
3. กดปุ่ม **Create new...** เพื่อสร้าง keystore ใหม่:
   - เลือกที่เก็บ: `C:\keystore\aile-coffee.jks` (สร้างโฟลเดอร์ keystore แยกไว้ที่ไดรฟ์ C — **อย่าเก็บในโฟลเดอร์โปรเจกต์** เพื่อจะได้ไม่หายอีก)
   - ตั้งรหัสผ่าน keystore และรหัสผ่าน key (จดเก็บไว้ให้แน่น เช่นบันทึกใน Notes หรือส่งอีเมลหาตัวเอง)
   - กรอกชื่อ/องค์กรตามสะดวก ส่วนอื่นปล่อยค่าเริ่มต้นได้
4. Next → เลือก **release** → Finish → รอสร้างเสร็จ
5. ไฟล์ APK จะอยู่ที่ `android\app\release\app-release.apk` — กดลิงก์ locate ที่แจ้งเพื่อเปิดโฟลเดอร์

### ขั้นที่ 6: ติดตั้งบนแท็บเล็ต/มือถือ
1. ส่งไฟล์ `app-release.apk` เข้าเครื่อง (แชร์ผ่าน LINE เข้าตัวเอง / คลาวด์ / สาย USB)
2. เปิดไฟล์เพื่อติดตั้ง (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" ถ้ามีถาม)
3. ต้องลบแอปเดิมก่อนจึงจะติดตั้งได้ เพราะ keystore ใหม่ไม่ตรงกับเดิม

### ขั้นที่ 7: ตรวจว่าได้เวอร์ชันใหม่จริง
- เปิดแอป ดูมุมล่างของหน้าล็อกอิน ต้องเห็นเลข **1.2.0**

## สิ่งที่ต้องเก็บไว้ครั้งนี้ (เผื่อรอบหน้า)
- ไฟล์ `C:\keystore\aile-coffee.jks` + รหัสผ่านทั้งสองตัว — สำเนาเก็บในคลาวด์ด้วย (Google Drive ฯลฯ)
- โฟลเดอร์โปรเจกต์ที่ `C:\aile-coffee-pos` — จำตำแหน่งนี้ไว้ ครั้งหน้าแค่ `git pull` หรือดาวน์โหลดโค้ดทับ

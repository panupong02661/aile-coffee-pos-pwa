# แก้แจ้งเตือน LINE หยุดส่ง (โควตารายเดือนหมด) + จบงาน Benchmark ที่ค้าง

## สาเหตุที่ยืนยันแล้ว (จากรูป + บันทึกระบบ)

ข้อความในรูปคือ LINE ตอบกลับว่า **"You have reached your monthly limit"** — บัญชี LINE Official Account แพลนฟรีส่งข้อความได้จำกัดต่อเดือน (ประมาณ 200 ข้อความ) และโควต้าเดือนนี้หมดแล้ว จึงส่งไม่ได้ตั้งแต่เมื่อวาน 10 โมงครึ่ง **ไม่ใช่ข้อผิดพลาดของแอป** — Discord ยังส่งได้ปกติ (เห็นในบันทึกว่าส่งสำเร็จ)

## ทางเลือกแก้ที่ต้องตัดสินใจ (เลือกได้หลายข้อ)

1. **รอโควต้ารีเซ็ต** — LINE รีเซ็ตโควต้าวันที่ 1 ของเดือนถัดไป ไม่ต้องทำอะไร แต่เดือนนี้จะไม่มีแจ้งเตือน LINE เลย
2. **อัปเกรดแพลน LINE OA** — ใน LINE Official Account Manager เปลี่ยนเป็นแพลนเสียเงิน (เช่น แพลนกลาง ~1,200 บาท/เดือน ส่งได้หลายพันข้อความ) ทำในเว็บ LINE เอง แอปไม่ต้องแก้อะไร
3. **ใช้ Discord เป็นช่องหลักชั่วคราว** — ระบบส่งเข้า Discord ได้อยู่แล้ว ปิด LINE ไว้จนกว่าโควต้าจะรีเซ็ต

## สิ่งที่จะทำในแอป (ไม่ว่าจะเลือกข้อไหน)

1. **แปลข้อความผิดพลาดเป็นภาษาไทยที่เข้าใจง่าย** — ตอนกด "ทดสอบ" หรือส่งไม่ผ่านเพราะโควต้าหมด ให้แสดง "โควต้าข้อความ LINE รายเดือนหมดแล้ว — รอรีเซ็ตวันที่ 1 ของเดือนถัดไป หรืออัปเกรดแพลนใน LINE Official Account Manager" แทน JSON ดิบ
2. **จบงาน Benchmark ที่ค้าง** — แก้ฟังก์ชันสรุป Benchmark (migration ที่ถูกยกเลิกกลางทาง): ใช้คอลัมน์ `menu_item_name` ที่ถูกต้องของตารางรายการสินค้า แล้วทดสอบเปิดหน้า Benchmark ให้เห็นตัวเลขบนกราฟ + จำนวนแก้วจริง

## Technical

- `supabase/functions/line-messaging/index.ts` และ/หรือ `src/pages/NotificationPage.tsx`: ตรวจ status 429 / ข้อความ "monthly limit" จาก LINE แล้วแสดงข้อความไทยพร้อมวิธีแก้
- Migration: DROP + CREATE `get_shop_benchmark(p_start)` แก้ `oi2.name` → `oi2.menu_item_name` (ตาราง order_items ไม่มีคอลัมน์ name) — ส่วนหน้าเว็บ Benchmark แก้เสร็จแล้วจากรอบก่อน
- ทดสอบ: เปิดหน้า Benchmark ด้วยบัญชี admin เห็นกราฟพร้อมตัวเลขและการ์ด "แก้วรวม"; กดทดสอบส่ง LINE เห็นข้อความไทยที่อธิบายโควต้า

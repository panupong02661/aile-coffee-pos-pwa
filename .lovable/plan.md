# ตอบคำถาม + แผนเพิ่มแจ้งเตือนออเดอร์หน้าร้าน

## 1. ใช้เครื่องพิมพ์ผ่านเบราว์เซอร์บน Windows ได้ไหม

ได้บางแบบ ขึ้นกับว่าเครื่องพิมพ์ต่อแบบไหน

- เครื่องพิมพ์ต่อสาย LAN / Wi-Fi (มีเลข IP): ใช้ได้เลย ไม่ต้องลงโปรแกรมเพิ่ม แค่ตั้งค่า IP และพอร์ต 9100 ในหน้า "ระบบเครื่องพิมพ์" โดยคอมกับเครื่องพิมพ์ต้องอยู่วง Wi-Fi/แลนเดียวกัน
- เครื่องพิมพ์ต่อสาย USB กับคอม: เบราว์เซอร์สั่งพิมพ์ตรงไม่ได้ ต้องใช้วิธีพิมพ์ผ่านหน้าต่างพิมพ์ของ Windows (เลือกเครื่องพิมพ์ในระบบ) หรือใช้แอปที่ติดตั้งลงเครื่องแทน
- Bluetooth: ใช้ได้เฉพาะเบราว์เซอร์ Chrome/Edge และต้องจับคู่ก่อน
- เปิดลิ้นชักเก็บเงินอัตโนมัติ: ทำได้เฉพาะเครื่องพิมพ์แบบ LAN/Wi-Fi

สรุปสำหรับ Windows: ถ้าเป็นเครื่องพิมพ์ LAN ใช้ได้ทันที ถ้าเป็น USB ต้องพิมพ์ผ่านหน้าต่างพิมพ์ของ Windows

## 2. การแจ้งเตือนเมื่อมีออเดอร์

สถานะจริงตอนนี้:

- ออเดอร์จากแอปลูกค้า (ออนไลน์): ส่งแจ้งเตือนออก Discord / LINE ตามที่ตั้งค่าไว้ เรียบร้อย
- ออเดอร์หน้าร้าน (POS): ยังไม่ส่งออกไปช่องทางภายนอก แม้ในหน้าตั้งค่าจะมีสวิตช์ "ออเดอร์ POS" อยู่ก็ตาม ระบบฝั่งเซิร์ฟเวอร์รองรับอยู่แล้ว แต่หน้าจอขายไม่ได้เรียกใช้

### สิ่งที่จะทำ

เมื่อชำระเงินสำเร็จที่หน้าขาย ให้ส่งข้อมูลออเดอร์เข้าระบบแจ้งเตือนเดียวกันกับออเดอร์ออนไลน์ โดย

- ทำงานเบื้องหลัง ไม่ถ่วงเวลาปิดการขาย และถ้าส่งไม่สำเร็จจะไม่กระทบการขาย
- เคารพสวิตช์ในหน้าตั้งค่าแจ้งเตือน: ถ้าปิด "ออเดอร์ POS" ก็ไม่ส่ง
- ส่งเฉพาะครั้งเดียวต่อออเดอร์ ไม่ส่งซ้ำตอนพิมพ์ใบเสร็จซ้ำหรือแยกบิล
- ข้อความจะแยกให้เห็นชัดว่าเป็นออเดอร์หน้าร้าน (ต่างจากออนไลน์)

### รายละเอียดทางเทคนิค

- เรียก `supabase.functions.invoke('send-order-notification')` หลังบันทึกออเดอร์สำเร็จใน `src/components/PaymentModal.tsx` (และเส้นทางแยกบิลใน `SplitBillModal.tsx` ถ้าบันทึกออเดอร์แยกเอง)
- ส่ง `order_source: 'pos'` เพื่อให้ edge function เลือก `pos_orders` settings ที่มีอยู่แล้ว
- ใช้รูปแบบ payload เดียวกับที่ `GlobalNotificationProvider.tsx` ส่งอยู่ (order_number, total_amount, order_items พร้อม addon, payment_method, shop_id)
- กันส่งซ้ำด้วย ref/ชุด order id ที่ส่งแล้วในหน่วยความจำของหน้า
- ทดสอบด้วย `supabase--curl_edge_functions` ด้วย `order_source: 'pos'` และตรวจ log
